file-stats 使い方

概要

指定したフォルダ内を再帰的に走査し、拡張子別のファイル数・合計サイズを集計して表示するCLIです。外部サービスとの連携はなく、ローカルのファイルシステムのみを参照します。

セットアップ（初回のみ）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"

実行方法

source .venv/Scripts/activate
file-stats [対象フォルダ]

対象フォルダ を省略した場合はカレントディレクトリを集計します。

オプション

オプション説明デフォルト
path（位置引数）集計対象のフォルダカレントディレクトリ
--top N合計サイズが大きい上位N件のみ表示する全件表示

実行例

# カレントディレクトリを集計
file-stats

# 対象フォルダを指定
file-stats C:\Users\me\Documents

# 上位5件のみ表示
file-stats C:\Users\me\Documents --top 5

出力例

拡張子              ファイル数       合計サイズ
.pyc                12      26.3KB
.py                 10       7.3KB
.html                1       3.4KB
.md                  3       2.3KB
(拡張子なし)          6       1.8KB
.txt                 5      654.0B

合計サイズが大きい拡張子から降順に表示されます。拡張子を持たないファイルは (拡張子なし) としてまとめて集計されます。

補足

  • サブフォルダ内のファイルも再帰的に集計対象になります
  • Git Bashで日本語が文字化けする場合は PYTHONIOENCODING=utf-8 file-stats のように環境変数を付けて実行してください
  • テスト実行は pytest tests/file_stats
