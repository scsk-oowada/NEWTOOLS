inandout 使い方

概要

SCSKの勤怠システム「SHARE/OTM」の出退勤打刻を自動化するCLIです。SHARE/OTMはメニューの「打刻」をクリックすると、出勤前なら「出勤」画面、退勤前なら「退勤」画面が自動的に表示される仕組みになっているため、このツールは自分で出勤/終業を選ぶのではなく、表示された内容を確認してそのまま打刻します。

SHARE/OTMは社内SSO（Microsoft Entra ID等）でログインするシステムです。このツールはツール専用のブラウザではなく、普段使っているMicrosoft Edgeのプロファイルを使って起動することで、SSOログイン済みの状態を引き継ぎます。実行前に、普段使っているEdgeのウィンドウをすべて終了しておく必要があります（Edgeのプロファイルは同時に複数のプロセスから使用できないため）。

セットアップ（初回のみ、開発・ビルドを行う場合）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"

実行方法

source .venv/Scripts/activate
inandout

実行すると、Edgeのプロファイルを使ってブラウザが起動し、SHARE/OTMのメニューから「打刻」を自動的に開きます。打刻対象の日付と区分（出勤/退勤）が表示され、yと答えると理由欄に固定の文言（Claude Code自動打刻）を入れて打刻を確定します。

前日の退勤など、未処理の打刻が複数残っている場合は、1件ずつ確認しながら処理します。未処理がなくなった時点で終了します。

実行結果の例

2026-10-16(金) の「退勤」を打刻します。よろしいですか？ (y/n): y
退勤を打刻しました。
打刻すべき対象はありません。

完了しました。Enterキーを押すと終了します。

補足

  • SHARE/OTMは画面遷移の正当性をサーバー側で厳しくチェックしているため、URLを直接開く、ブックマークから開く、リロードするといった操作はできません。このツールは必ずメニューの「打刻」リンクをクリックする形で画面を開きます
  • 理由欄には固定で「Claude Code自動打刻」という文言が入ります
  • 通勤手当の区分は、画面の初期値（対象外）のまま変更しません
  • テスト実行は pytest tests/inandout（SHARE/OTMへの実際のアクセス・ブラウザ操作は含まず、打刻情報の表示整形・Edgeプロファイルのパス解決のみを検証します）
