mymap-csv 使い方

概要

座標（緯度・経度）のリストから、Google My Mapsの「インポート」機能で読み込めるCSVファイルを作成するCLIです。Google My Mapsには公式のAPIがないため、--map-url を指定した場合はPlaywrightでブラウザを操作し、既存の地図に新しいレイヤーとしてCSVをインポートして画面に表示します（UI操作の自動化のため、Googleの仕様変更で動作しなくなる可能性があります）。--map-url を指定しない場合は、これまでと同様にCSV作成のみを行い、My Mapsへの読み込みはご自身で行っていただきます。

セットアップ（初回のみ）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"

入力ファイルの形式

テキストファイルに1行1件、次のいずれかの形式で座標を記載します。

# 緯度,経度 のみ（名前は座標そのものになる）
34.702485,135.495951

# 緯度,経度,地名（地名を指定すると、それがピンの名前になる）
35.681236,139.767125,東京駅

全角カンマ（，）が混ざっていても自動的に半角に変換して解析します。逆ジオコーディング（座標から自動で地名を判定する機能）は実装していません。地名を付けたい場合は3列目に手動で入力してください。

実行方法

source .venv/Scripts/activate
mymap-csv 入力ファイル.txt

実行すると、入力ファイルと同じ場所に同名の .csv ファイルが作成されます。

オプション

オプション説明デフォルト
input（位置引数）座標リストのテキストファイル（--login 指定時は不要、それ以外は必須）
--output ファイルパス出力するCSVファイルのパス入力ファイル名の拡張子を .csv に変えたもの
--map-url URLCSVをインポートする既存のGoogle My MapsのURL。指定すると、CSV作成後にブラウザでその地図を開き、新しいレイヤーとしてCSVをインポートして表示する環境変数 MYMAP_URL（未設定なら自動インポートは行わずCSV作成のみ）
--loginブラウザを表示してGoogleへ手動でログインし、そのログイン状態を保存する（フラグ）

実行例

mymap-csv pins.txt
mymap-csv pins.txt --output C:\Users\me\Desktop\mymap.csv

Google My Mapsへ自動でピンを表示する（--map-url オプション）

CSVを作るだけでなく、そのままGoogle My Mapsに読み込んでピンが立った地図を表示させたい場合は、次の手順で行います。

1. 初回のみ：Googleへログインし、ログイン状態を保存する

mymap-csv --login

ブラウザが開くので、そこで通常どおりGoogleアカウントにログインします。My Mapsの地図一覧が表示されたら、コマンドを実行しているターミナルに戻ってEnterキーを押してください。ログイン状態は %USERPROFILE%\.newtools\mymap_csv_session.json に保存され、以降はこのファイルを使って自動的にログイン済み状態を再現します（IDやパスワードをスクリプトに自動入力する方式は、Googleに不審なログインとして検知・ブロックされやすいため採用していません）。

2. CSVを既存の地図にインポートして表示する

あらかじめ用意しておいた既存のMy MapsのURL（編集画面のURL）を --map-url で指定します。

mymap-csv pins.txt --map-url "https://www.google.com/maps/d/edit?mid=＜地図のID＞"

毎回同じ地図を使う場合は、環境変数 MYMAP_URL に地図のURLを設定しておけば --map-url を省略できます。

export MYMAP_URL="https://www.google.com/maps/d/edit?mid=＜地図のID＞"
mymap-csv pins.txt

実行すると、保存済みのログイン状態でブラウザが開き、指定した地図に新しいレイヤーを追加してCSVを自動でインポートします。実行するたびに新しいレイヤーが追加されるため、既存のピンは消えずに地図に積み重なっていきます。列選択のウィザードも可能な範囲で自動的に進めますが、Google側のUI変更などで途中で止まった場合は、表示されたブラウザ上でそのまま手動で操作を完了してください。地図の内容を確認したら、ターミナルに戻ってEnterキーを押すとブラウザが閉じます。

Google My Mapsへ手動で読み込む方法（--map-url を使わない場合）

  1. Google My Maps を開き、新しい地図を作成（または既存の地図を開く）
  2. レイヤーの「インポート」をクリック
  3. このツールで作成したCSVファイルを選択
  4. 緯度・経度の列を指定する画面が出た場合は「緯度」「経度」列を選択し、タイトルに使う列として「名前」を選択

出力例（CSV）

名前,緯度,経度
東京駅,35.681236,139.767125
34.702485,135.495951,34.702485,135.495951

補足

  • 地名を指定しなかった行は、名前の列に座標（緯度,経度）がそのまま入ります
  • 緯度・経度が数値として読み取れない行や、列数が2列・3列以外の行がある場合はエラーとして知らせ、処理を中断します
  • --map-url によるブラウザ自動操作は、Google My MapsのUIを直接操作する仕組みのため、Google側の仕様変更で動作しなくなる可能性があります。うまく進まない場合は、表示されたブラウザ上で残りの操作を手動で行ってください
  • ログイン状態は %USERPROFILE%\.newtools\mymap_csv_session.json に平文で保存されます。共有PCなどでは取り扱いに注意してください
  • テスト実行は pytest tests/mymap_csv
