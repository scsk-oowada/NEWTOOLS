teams-schedule 使い方

前提

  • Outlookデスクトップアプリがインストールされ、業務用アカウントでログイン済みであること
  • Azure AD認証・アプリ登録は不要（ローカルのOutlookとCOM連携するため）

セットアップ（初回のみ）

cd /c/ProgramData/NEWTOOLS
source .venv/Scripts/activate
pip install -e ".[dev]"

実行方法

source .venv/Scripts/activate
teams-schedule

オプション

オプション説明デフォルト
--start YYYY-MM-DD取得開始日本日
--end YYYY-MM-DD取得終了日（この日を含む）開始日から7日後

実行例

# 今日から7日間（デフォルト）
teams-schedule

# 期間を指定
teams-schedule --start 2026-09-01 --end 2026-09-05

出力例

2026-08-20 15:30 - 2026-08-20 16:30 [Teams] [FY26] M141ホンダ案件関連定例会
2026-08-21 09:00 - 2026-08-21 17:30  ●リモートワーク（出社なし）

[Teams] が付いている行はTeams会議（予定本文にTeams参加リンクを含む）です。

補足

  • Git Bashで日本語が文字化けする場合は PYTHONUTF8=1 teams-schedule のように環境変数を付けて実行してください
  • テスト実行は pytest
