rizab-my-schedule 使い方

概要

りざぶ郎（宇都宮・大宮の会議室予約システム）にログインし、自分が予約している会議室の予定を取得して、Outlook予定表に自動登録するツールです。exe化してダブルクリックするだけで実行できるようにすることを想定しています。

ログイン情報（グループID・パスワード・氏名）は初回実行時に一度だけ入力すれば、Windows DPAPIで暗号化してローカルに保存されます。以降はダブルクリックだけで、本日から30日先までの自分の予約を取得します。取得結果は日付・時間・会議室名の一覧として画面に表示され、矢印キー（↑↓）とスペースキーで予約ごとに登録するかどうかを選び、Enterで確定した分だけOutlook予定表に登録されます（登録すると、同じ予定がTeamsの予定表にも自動的に反映されます）。

りざぶ郎の予約情報取得・ログインには、画面が内部で呼び出しているAjax API・ログインフォームへの直接リクエストを利用しています（ブラウザは起動しません）。りざぶ郎側の仕様変更で動作しなくなる可能性があります。

セットアップ（初回のみ、開発・ビルドを行う場合）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"

コマンドラインでの実行

source .venv/Scripts/activate
rizab-my-schedule

初回実行時は以下を対話入力で聞かれます。

入力項目内容
グループID予約表URLの g= の値
パスワードりざぶ郎のログインパスワード
氏名りざぶ郎の予約者表示に一致する氏名（名字のみ）。自分の予約かどうかの判定に使う

入力内容は %APPDATA%\newtools\rizab_my_schedule\config.bin にDPAPIで暗号化して保存されます。実行したユーザー・PCでなければ復号できません。パスワードは入力ミスに気付けるよう画面に表示されます。グループIDまたはパスワードが誤っていてログインに失敗した場合は、保存済みの設定を自動的に削除するので、次回実行時に再入力してください（手動で削除したい場合は、このファイルを削除してから再実行してください）。

exe化（ダブルクリックで実行する場合）

PyInstallerで1ファイルのexeにビルドします。

pip install -e ".[dev]"
pyinstaller --onefile --console --name rizab-my-schedule --hidden-import win32timezone ^
    src/newtools/rizab_my_schedule/cli.py

dist/rizab-my-schedule.exe が生成されます。この1ファイルを他のPCにコピーして配布できます。

他のPCで使う場合の事前準備

ブラウザ（Chromium）は使用しないため、Playwrightのインストールやplaywright installの実行は不要です。配布先のPCで用意してもらう必要があるのは以下だけです。

  1. rizab-my-schedule.exe を配布先PCの任意のフォルダにコピーする
  2. 配布先PCにクラシック版Outlookデスクトップアプリがインストール・設定済み（配布先の利用者自身のメールアカウントでサインイン済み）であることを確認する（新Outlook・Web版Outlookでは動作しません）
  3. rizab-my-schedule.exe をダブルクリックして実行する（初回実行時に、その利用者自身のりざぶ郎グループID・パスワード・氏名の入力が必要）
りざぶ郎の予約表URL（www.r326.com）に配布先PCからアクセスできるネットワーク環境であることも必要です。また、社内で配布されていない実行ファイルのため、Windows SmartScreenやウイルス対策ソフトが警告を出す場合があります。

実行結果の例

矢野 さんの予約を 2026-09-08 から 2026-10-07 まで取得します...
2 件の予約を取得しました。
Outlook/Teamsに登録するスケジュールを選択してください。
　>を矢印キーで動かし、登録する場合はSpaceキーを入力すると登録対象に × が付きます
↑↓:移動  スペース:登録するか切り替え  Enter:確定

    日付            時間            会議室
>  [x] 2026-09-08(火)  10:00-11:00     宇都宮 会議室2（右から2番目）
   [x] 2026-09-09(水)  13:00-14:00     大宮 会議室1（6人用）

Outlook予定表に登録しました（新規 2 件 / 既存のためスキップ 0 件）。

完了しました。再実行しますか？ (y/n):

矢印キー（↑↓）で選択中の予約（>で示される行）を移動し、スペースキーで登録するかどうか（[x]/[ ]）を切り替え、Enterキーで確定します。既定では全件チェック済みなので、登録したくない予約だけスペースキーで外してください。1件もチェックしないままEnterを押すと登録は行われません。

登録される予定は、件名にりざぶ郎の予約件名（未入力の場合は「拠点 会議室名」）、場所に「拠点 会議室名」が設定されます。

Teamsの予定表はOutlookと同じExchangeカレンダーを参照しているため、Outlookに登録した予定はTeamsの予定表にも自動的に反映されます。別途Teams向けの登録は不要です。

最後に「再実行しますか？ (y/n)」と聞かれます。yと答えると設定はそのまま使い、りざぶ郎から予約を取得し直して同じ操作を繰り返します。y以外を入力するとツールを終了します。

補足

  • 対象は宇都宮・大宮の会議室のみです（社用車・ゲストカード・豊洲などは対象外）
  • 取得期間は実行日から30日間で固定です（コード上の FETCH_DAYS を変更すれば調整できます）
  • 自分の予約かどうかは、設定した氏名（名字のみ）でりざぶ郎の予約者表示の前方一致判定を行います（予約者表示が「名字のみ」「名字＋名前」のどちらでも一致します）
  • Outlook登録は同じ件名・開始時刻の予定が既にある場合はスキップし、二重登録しません。スキップした予定がある場合は、その日付・時間・会議室を一覧表示します
  • テスト実行は pytest tests/rizab_my_schedule（ログイン・API呼び出し・Outlook COM呼び出しは含まず、設定保存・フィルタ判定・件名整形・選択画面の表示内容のみを検証します）
