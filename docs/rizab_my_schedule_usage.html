rizab-my-schedule 使い方

概要

りざぶ郎（宇都宮・大宮の会議室予約システム）にログインし、自分が予約している会議室の予定を取得して、Outlook予定表に自動登録するツールです。exe化してダブルクリックするだけで実行できるようにすることを想定しています。

ログイン情報（グループID・パスワード・氏名）は初回実行時に一度だけ入力すれば、Windows DPAPIで暗号化してローカルに保存されます。以降はダブルクリックだけで、本日から30日先までの自分の予約を取得し、Outlookに登録します。

りざぶ郎の予約情報取得には、画面が内部で呼び出しているAjax API（rizab-summaryと同じ仕組み）を利用しています。りざぶ郎側の仕様変更で動作しなくなる可能性があります。

セットアップ（初回のみ、開発・ビルドを行う場合）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"
playwright install chromium

コマンドラインでの実行

source .venv/Scripts/activate
rizab-my-schedule

初回実行時は以下を対話入力で聞かれます。

入力項目内容
グループID予約表URLの g= の値
パスワードりざぶ郎のログインパスワード
氏名りざぶ郎の予約者表示に一致する氏名（名字のみ）。自分の予約かどうかの判定に使う

入力内容は %APPDATA%\newtools\rizab_my_schedule\config.bin にDPAPIで暗号化して保存されます。実行したユーザー・PCでなければ復号できません。設定をやり直したい場合は、このファイルを削除してから再実行してください。

exe化（ダブルクリックで実行する場合）

PyInstallerで1ファイルのexeにビルドします。

pip install -e ".[dev]"
pyinstaller --onefile --console --name rizab-my-schedule --hidden-import win32timezone ^
    src/newtools/rizab_my_schedule/cli.py

dist/rizab-my-schedule.exe が生成されます。デスクトップなどに置いてダブルクリックすれば実行できます。

このexeはPlaywright・Chromium・Outlookがセットアップ済みの自分のPC専用です（Chromium本体はexeに同梱されないため、実行環境に playwright install chromium が必要です）。他のPCへ配布する用途には対応していません。

実行結果の例

矢野 さんの予約を 2026-09-08 から 2026-10-07 まで取得します...
1 件の予約を取得しました。
Outlook予定表に登録しました（新規 1 件 / 既存のためスキップ 0 件）。

完了しました。Enterキーを押すと終了します。

登録される予定は、件名にりざぶ郎の予約件名（未入力の場合は「拠点 会議室名」）、場所に「拠点 会議室名」が設定されます。

補足

  • 対象は宇都宮・大宮の会議室のみです（社用車・ゲストカード・豊洲などは対象外）
  • 取得期間は実行日から30日間で固定です（コード上の FETCH_DAYS を変更すれば調整できます）
  • 自分の予約かどうかは、設定した氏名とりざぶ郎の予約者表示（名字のみ）の完全一致で判定します
  • Outlook登録は同じ件名・開始時刻の予定が既にある場合はスキップし、二重登録しません
  • テスト実行は pytest tests/rizab_my_schedule（ログイン・API呼び出し・Outlook COM呼び出しは含まず、設定保存・フィルタ判定・件名整形部分のみを検証します）
