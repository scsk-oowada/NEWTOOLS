kado-yosoku 使い方

概要

フレックス管理表（Excel、月ごとにシートが分かれている勤怠表）を読み込み、従業員ごとの稼働率の推移から翌月の稼働率を線形トレンドで予測するCLIです。

稼働率は次の式で算出します。

稼働率 = (目安時間 + 残業時間（当月）) ÷ 標準総労働時間
  • 目安時間・残業時間は従業員ごとの列（列19・列8）から取得します
  • 標準総労働時間（列21）はシート内の全従業員で共通の値です

セットアップ（初回のみ）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"

実行方法

source .venv/Scripts/activate
kado-yosoku 対象ファイル.xlsx

オプション

オプション説明デフォルト
path（位置引数）対象のExcelファイル（必須）
--sheets集計対象シート名をカンマ区切り・時系列順で指定する8月,9月,10月
--target-label予測対象月の表示ラベル11月
--output予測シートを追加した新しいExcelファイルの保存先。指定すると、直近シート（--sheetsの最後）と同じ体裁の新シートを作り、氏名・残業(当月)・目安時間・標準総労働時間の4列のみ予測値で埋めて、別ファイルとして保存する。元ファイルは変更しない（省略時は画面表示のみ）
--force--outputの保存先が既に存在する場合でも上書きする上書きしない

実行例

# 既定（8月・9月・10月から11月を予測、画面表示のみ）
kado-yosoku "M141_ジョイント稼働予測.xlsx"

# 11月シートを追加した新しいファイルを作成する
kado-yosoku "M141_ジョイント稼働予測.xlsx" --output "M141_ジョイント稼働予測_11月追加.xlsx"

# 翌月（12月）を作る場合は、--sheets と --target-label を1ヶ月分ずらす
kado-yosoku "M141_ジョイント稼働予測_11月追加.xlsx" --sheets 9月,10月,11月 --target-label 12月 --output "M141_ジョイント稼働予測_12月追加.xlsx"

出力例

氏名                8月        9月       10月       11月予測
杉山　雄太          95.6%     98.4%    100.6%      103.2%
鈴木　大輔         120.9%    108.7%    116.6%      111.1%

チーム全体の11月平均稼働率予測: 105.0%

補足

  • 予測は各従業員の月次稼働率（および残業時間・目安時間・標準総労働時間）に最小二乗法の直線を当てはめ、次の月の値を外挿する方式です
  • 対象シートが2つ以下、またはいずれかのシートで同名の従業員が見つからない場合は正しく予測できません
  • --outputで追加される新シートは、氏名・残業(当月)・目安時間・標準総労働時間の4列のみ予測値が入り、資格や36協定などその他の列は空白になります
  • 新シートの右側に残る「氏名＋社員番号」の参考テーブル（コピー元シートの11〜17行目相当）はそのままコピーされるため、必要に応じて手動で確認してください
  • Git Bashで日本語が文字化けする場合は PYTHONIOENCODING=utf-8 kado-yosoku ... のように環境変数を付けて実行してください
  • テスト実行は pytest tests/kado_yosoku
