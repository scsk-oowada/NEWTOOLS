rizab-summary 使い方

概要

会議室予約システム「りざぶ郎」（宇都宮・大宮の会議室）から予約情報を取得し、予約者ごとの一覧をTXTファイルに出力するCLIです。りざぶ郎自体にはファイル出力機能がないため、Playwrightでログインした上で、画面が内部で呼び出しているAjax API（予約表の日付ジャンプ・予約一覧取得）を直接呼び出し、タブ区切りテキストとして返る予約データを取得します。画面をクリックして読み取る方式ではないため、高速かつ確実に取得できます。--register-outlook を付けると、取得した予約をOutlook予定表にも登録します。

利用しているAPI（main.aspx・a.aspx）はりざぶ郎の公開仕様ではなく、画面のJavaScriptを解析して判明したものです。りざぶ郎側の仕様変更で動作しなくなる可能性があります。ログインに失敗する場合は --headed オプションでブラウザ画面を表示しながら実行し、動作を確認してください。

セットアップ（初回のみ）

cd /c/ProgramData/NEWTOOLS
python -m venv .venv
source .venv/Scripts/activate
pip install -e ".[dev]"
playwright install chromium

環境変数

りざぶ郎の予約表ID（URLの g= の値）とログインパスワードは、コマンドやファイルに直接書かず環境変数で指定します。パスワードは会話やチャットに平文で貼らないよう注意してください。

環境変数内容
RIZABU_GROUP_ID予約表ID（例: https://www.r326.com/b/main.aspx?g=xxxxx の xxxxx 部分）
RIZABU_PASSWORDりざぶ郎のログインパスワード
# PowerShellの例
$env:RIZABU_GROUP_ID = "xxxxxxxxxxxxxxxxx"
$env:RIZABU_PASSWORD = "xxxxxxxx"

実行方法

source .venv/Scripts/activate
rizab-summary

省略時は本日から7日後までの予約を取得します。

オプション

オプション説明デフォルト
--start YYYY-MM-DD集計開始日本日
--end YYYY-MM-DD集計終了日（この日を含む）開始日から7日後
--output ファイルパス出力するTXTファイルのパスrizab_schedule_<開始日>_<終了日>.txt
--register-outlook取得した予約をOutlook予定表にも登録する登録しない
--headedブラウザ画面を表示して実行する（動作確認用）非表示（headless）

実行例

# 本日から1週間分を取得してTXT出力
rizab-summary

# 期間を指定してOutlookにも登録
rizab-summary --start 2026-09-01 --end 2026-09-07 --register-outlook

# ログインがうまくいくか確認したい場合
rizab-summary --headed

出力例（TXT）

■ 矢野
  2026-08-25(火) 10:00-11:00  宇都宮 会議室2（右から2番目）

■ 五百木
  2026-08-25(火) 08:30-10:00  宇都宮 大会議室

補足

  • 対象は宇都宮・大宮の会議室のみです（社用車・ゲストカード・豊洲は対象外）
  • りざぶ郎には参加者を記録する項目がないため、参加者情報は取得しません
  • 氏名はりざぶ郎の表示に合わせて名字のみを扱います（りざぶ郎自体がフルネーム保存禁止のため）
  • Outlook登録は同じ件名・開始時刻の予定が既にある場合はスキップし、二重登録しません
  • テスト実行は pytest tests/rizab_summary（ログイン・API呼び出し部分は含まず、データ解析・整形部分のみを検証します）
